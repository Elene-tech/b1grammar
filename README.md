# Grammarway 2 — Grammar Trainer

Интерактивный тренажёр английской грамматики по программе учебника **Grammarway 2**
(Dooley & Evans, Express Publishing) · British English.

Мобильное и десктопное веб-приложение (PWA): правила простыми словами на трёх языках
(русский / українська / English), тренировочные упражнения с обязательным вводом ответа,
Round-up повторения, геймификация (XP, уровни, медали, бейджи, серия дней).

> Контент написан заново по темам учебника (те же грамматические цели, новые предложения) —
> оригинальные задания книги не копируются.

## Что внутри (MVP)

- **Units 1–5**: Present Continuous / Present Simple · Past Simple + used to ·
  Past Continuous · Present Perfect · Future forms (will / going to / present tenses).
- **Round-up 1**: 24 смешанных задания по юнитам 1–5 с нарастающей сложностью.
- Каждый юнит: теория (3 языка) → Warm-up → Core practice → Challenge.
- Типы заданий: ввод пропущенного слова, выбор варианта (позиция ключа балансируется
  — никогда не по порядку A-B-C и не на одном месте), сборка предложения,
  переписывание (transform), сопоставление пар.
- Каждое задание можно проходить неограниченно; порядок вариантов перемешивается
  при каждой попытке.
- Прогресс хранится на устройстве (localStorage), есть экспорт/импорт кода
  для переноса между устройствами.

## Стек

React + TypeScript + Vite · Tailwind CSS · Zustand (persist) · vite-plugin-pwa.
Без бэкенда — статическое приложение.

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # dist/
npm run preview    # проверка сборки
```

## Деплой на Vercel

1. Создайте репозиторий на GitHub и запушьте этот проект
   (`node_modules` и `dist` в `.gitignore` — не заливайте их).
2. На [vercel.com](https://vercel.com) → **Add New Project** → импортируйте репозиторий.
3. Настройки подхватятся автоматически (`vercel.json`): build `npm run build`, вывод `dist`.
4. Каждый push в `main` — автоматический деплой.

Приложение можно установить на телефон («Добавить на главный экран»)
и на десктоп (установка PWA) — работает офлайн после первой загрузки.

## Структура

```
src/
├─ content/        данные юнитов и Round-up (теория + задания, i18n RU/UA/EN)
├─ engine/         нормализация ответов, перемешивание, балансировка позиций ключа
├─ store/          прогресс, XP, уровни, серия, бейджи (Zustand + persist)
├─ components/     ExercisePlayer, Layout
├─ pages/          Onboarding, Home, Map, Unit/Round-up, Profile
└─ lib/            звук, прогресс/разблокировка, hash-роутер
```
